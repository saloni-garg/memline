Or connect Claude and Cursor directly (MCP)

      
With the live connection, those tools read what Memline understands about you themselves, and can propose new understandings to your inbox as you work. Create an API key in Settings, then either use the hosted connection (server URL shown with your key) or run the local server with this configuration:

      
{
  "mcpServers": {
    "memline": {
      "command": "python",
      "args": ["-m", "app.mcp_server"],
      "env": { "MEMLINE_DB": "memline.db", "MEMLINE_USER": "you@example.com" }
    }
  }
}

      
Tools available to your assistants: recall_memory, propose_memory (lands in your inbox, never straight into what is kept), and forget_memory.
